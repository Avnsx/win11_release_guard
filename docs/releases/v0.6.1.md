# v0.6.1 Release Notes

Date: 2026-10-09 · Full notes: [Release v0.6.1 in the Pages wiki](https://avnsx.github.io/win11_release_guard/wiki/Release-v0.6.1/) · [Changelog](https://avnsx.github.io/win11_release_guard/wiki/changelog/v0.6.1/)

## Key Changes

| Area | What changed |
| --- | --- |
| Dashboard controls | Expand View and the filters keep working after a same-tab download link or a back/forward return. |
| Latest updates | The expanded diagnostics list each Windows 11 version's latest update date, build, KB, and Microsoft support article. |
| Dates | Every dashboard date reads like "Friday, 9 October 2026, 15:52:04 CEST"; explicit UTC timestamps stay UTC. |
| Failure issue | A failed signed generation or validation reports its error text in the managed GitHub issue. |
